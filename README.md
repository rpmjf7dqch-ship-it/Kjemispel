# Kjemispel

Eit interaktivt kjemispel for å øve på periodesystemet, oksid, syrer og basar og organiske redoksreaksjonar. Spelet køyrer direkte i nettlesaren og gir tilbakemelding undervegs.

Dette er eit personleg læringsprosjekt der eg utforskar korleis kjemifaglege tema kan gjerast til digitale øvingsoppgåver.

## Spelmodusar

- **Periodesystem Wordle:** Skriv grunnstoffsymbolet som høyrer til det oppgitte atomnummeret. Vel mellom uavgrensa forsøk og ein vanskelegare modus med tre liv.
- **Oksid:** Marker grunnstoff som er knytte til basiske, amfotære og sure oksid i oppgåvene.
- **HSAB:** Øv på harde og mjuke syrer og basar gjennom korte tekstsvar og val i periodesystemet.
- **Organisk redoks:** Vel oksidasjons- eller reduksjonsmiddel til ulike reaksjonar. Oppgåvene blir viste som tekst eller som ei blanding av tekst og formlar.

## Slik startar du

1. Last ned prosjektet via **Code → Download ZIP** på GitHub.
2. Pakk ut ZIP-fila.
3. Opne `index.html` i ein nettlesar.

Du treng ikkje Python eller andre installasjonar. La `index.html`, `style.css`, `script.js` og alle PNG-bileta liggje i same mappe, med dei opphavlege filnamna.

## Teknologi og utvikling

Nettversjonen er laga med HTML, CSS og JavaScript, utan rammeverk eller byggesteg. Prosjektet er utvikla ved hjelp av AI-assistert koding og spring ut av interessa mi for kjemi og digitale læringsverktøy.

## Om svara i spelet

Oppgåvene brukar førehandsdefinerte fasitar. Fritekstsvara i HSAB-modusen blir vurderte ved hjelp av nøkkelord, ikkje ei fagleg tolking av heile svaret. Kjemifaglege samanhengar er forenkla for øving, og innhaldet bør brukast saman med pensum og undervisning.

Prosjektet er under utvikling. I den noverande HSAB-modusen lukkar ikkje «Avbryt» tekstspørsmålet; spørsmålet blir vist på nytt.
